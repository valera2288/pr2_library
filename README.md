# Практическая работа №2 — списки, поиск, фильтрация и пагинация

Клиент библиотечной системы: книги и авторы на данных в памяти. Слои models, repositories, state, screens, widgets, состояние на provider, условия отбора хранятся в адресе (`/books?search=мир&sort=year,desc&page=2`).

## Запуск

```
flutter pub get
flutter run -d chrome --web-port=5555
```
